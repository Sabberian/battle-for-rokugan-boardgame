# Битва за Рокуган: игра и подключение к Zarya

Полная игра на 2–5 игроков с лобби по образцу Cyclades: участники занимают места, выбирают кланы, хозяин запускает партию. Отдельная готовность не требуется. В iframe навигацию, приглашения и выход оставляет платформе.

Добавлены `zarya-game.json` с наблюдаемыми полями каталога, Docker/Compose, постоянное хранение матчей, CORS публичного адреса и проверка `/platform` API. Инструкция регистрации в закрытом проекте платформы — `docs/SITE-INTEGRATION.md`.

Проверки: `npm test`, `npm run build`, `npm run test:platform`; браузерный вход двух игроков, выбор кланов и запуск хозяином. Docker CLI в среде подготовки отсутствует; контейнер нужно проверить перед выкладкой.

Сервис и поддомен ещё не развёрнуты. Предлагаемый ID каталога: `rokugan`, имя boardgame.io: `battle-for-rokugan`.
